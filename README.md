# SSH Key Generator & Connector

A cross-platform Python GUI app to generate SSH keys and connect to remote servers using those keys.

## Features

- Generate RSA or ED25519 SSH key pairs
- Set passphrase and comment for keys
- Save keys to custom locations
- Connect to remote servers via SSH using generated keys
- Run commands on remote servers

## Setup

1. Install Python 3.x
2. Install dependencies:
    pip install -r requirements.txt
3. Run the app:
    python main.py

## Notes

- For Windows and Linux.
- Requires Python's `tkinter` and `paramiko` libraries.
